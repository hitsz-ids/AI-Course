# 📈 量化交易学习路径 · 从零到研究实战

> 本仓库记录了一套系统的量化交易学习路线，分为三个渐进阶段。
> 适合对金融 + 编程 + 机器学习感兴趣的交易爱好者。

---

## 🗂 学习阶段

### 阶段一：初识量化 · 从一只股票开始

从单只股票出发，理解量化交易的基本概念与工作流程：数据获取、技术指标计算、回测框架搭建。

📁 [初识量化：从一只股票开始](./初识量化：从一只股票开始)

### 阶段二：如何用 AI 方式量化选股

引入机器学习模型，利用 AI 方法构建选股因子、训练预测模型，实现从单只股票到全市场的扩展。

📁 [如何用AI方式量化选股](./如何用ai方式量化选股)

### 阶段三：如何用 Research 方式完成量化选股

结合研究方法论，通过深度研报分析、因子挖掘与组合优化，形成一套可复现的量化选股研究体系。

📁 [如何用Research方式完成量化选股](./如何用Research方式完成量化选股)

## 🚀 快速开始

```bash

```
